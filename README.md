# HexPerator
This is a tool that seperates hexadecimal with spaces, here's how it works:
1. You put hexadecimal binary in the input (without 0x), this is intended for converting hexadecimal binary's that was once a midi file, but this works for every day use!


2. The site uses JavaScript to put the first 2 characters in the output, then it adds a space, and the cycle repeats until it has stumbled across the last 2 characters of the hexadecimal string.


3. Copy the string with the copy button, surprisingly, the copy to clipboard mechanism is most of the JavaScript!
